# Unblocked Games Hub

A premium dark-mode game dashboard inspired by modern launcher UX, built with React, Vite, Tailwind CSS, and Lucide React.

## Features
- Responsive game dashboard with dark gaming aesthetic
- Sidebar-based category filtering
- Search bar for game discovery
- Theater-style modal with embedded iframe gameplay
- Fullscreen toggle for a cleaner play experience
- Stealth mode that changes the browser tab title and favicon to blend in
- Mock catalog structure to easily add more games later

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```
